# 実装タスクリスト

[spec.md](./spec.md) を実装に落とし込んだ作業リストです。**ループ実行時の唯一の状態ファイル**であり、進捗はこのファイルのチェックボックスだけが持ちます。

## 🎯 ゴール

`spec.md` の内容をすべて実装し、`styles.css` を import するだけで記事が書けて公開できるライブラリにする。

## 運用ルール

- **1タスクずつ順に進める。** 1ターンで複数タスクを続けてよいが、まとめて実装しない
- 各タスクごとに **ゲートを通してからコミット**する。通らなければそこで止まる
- 完了の条件は **`npm test && npm run build` が通ること**。通らないうちはチェックを付けない
- `npm test` は **`tsc --noEmit` を含む**。`npm run build`（tsup）は型を見ないため、これが無いと型エラーを素通りさせる
- **（テスト → 実装 → グリーン）** と書かれたタスクは、テストを先に書いて落ちることを確かめ、実装で通すところまでを**1周回で閉じる**。赤い状態を次の周回に持ち越さない
- 1タスク = 1コミット。コミット後にこのファイルのチェックを付ける
- `dist/` はコミット対象。`src/` を変えたら必ずビルドしてから commit する（spec §12）
- **判断に迷ったら止めて質問する。** spec に書かれていないことを推測で実装しない
- spec §17 の「意図的に受け入れている制約」は**直さない**

### フェーズ9: GitHub 連携（spec §15）

`github` prop を渡したときだけ有効。渡さなければ v1 の挙動（ダウンロードのみ）を変えない。
**この不変条件をフェーズ全体の回帰テストとして最初に固定する。**

#### 9-1 土台

- [x] `github` を渡さないとき既存の挙動が一切変わらないことをテストで固定する（ボタン文言・ダウンロード・ログイン画面が出ないこと。テスト → グリーン）

#### 9-2 認証（Fine-grained PAT）

**GitHub App のログインは断念した。** `login/oauth/access_token` に CORS が無く、
ブラウザから `code` を交換できない（SPA 対応は Preview / Paused）。詳細は spec §15。
`api.github.com` は CORS 対応なので 9-3 以降はそのまま進められる。

- [x] `tokenStorage` の `expiresAt` を任意にする（PAT には期限情報が無い。無期限扱いでタブを閉じるまで保つ。テスト → 実装 → グリーン）
- [x] `src/github/verifyToken.ts` — `GET /repos/{repo}` で読めることと `permissions.push` を確かめる。401 / 404 / 権限不足を区別する（テスト → 実装 → グリーン）
- [x] `useGitHubToken` フック — 貼り付け・検証・保存・破棄をまとめ、`{ status, token, error, submit, clear }` を返す（テスト → 実装 → グリーン）
- [x] 関門をトークン入力欄に差し替える（`type="password"`、保存後は再表示しない）。あわせて GitHub App 用のコード（`pkce` / `authUrl` / `exchangeCode` / `navigate` / `useGitHubAuth` と `tokenStorage` の PendingAuth）を消し、`GitHubConfig` から `clientId` と `redirectUri` を外す（テスト → 実装 → グリーン）
